## 四、每周怎么上传作业（零基础版）

在项目根目录打开终端，依次执行三条命令即可：

```bash
git add .
git commit -m "第05周实验：完成 XXX"
git push
```

三步的含义：

1. `git add .` —— 把本周改动的文件**放进待提交的篮子**里；
2. `git commit -m "说明"` —— 给这次改动**拍一张快照**并写上备注；
3. `git push` —— 把快照**上传到 GitHub**。
